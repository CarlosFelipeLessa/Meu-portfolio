# Project Constitution & Governance (gemini.md)

## 1. Project Identity & North Star
- **Project Name:** DevPortfolio Pro Max (Recruiter-First Executive Developer Portfolio)
- **Goal:** Conceive, architect, and implement an ultra-high-conversion developer portfolio designed specifically for Tech Recruiters, Hiring Managers, and Engineering Managers.
- **Core Methodology:** BLAST Framework (Blueprint -> Links -> Architecture -> Stylization -> Trigger) combined with UI/UX Pro Max standards.

## 2. Non-Negotiable Architectural Rules
1. **Recruiter-First Escaneability:** The 5-second scan rule must be satisfied. Value proposition, role seniority, stack badges, CV download, and contact channels must be visible above the fold.
2. **STAR Method for Projects:** Every project case study must explicitly present:
   - **Situation/Problem**: Business & engineering context.
   - **Action/Architecture**: Technical decisions, trade-offs, and design patterns.
   - **Technologies**: Exact stack tags.
   - **Results/Metrics**: Measurable business impact (latency reduction, uptime, cost savings, user scale).
3. **No Abstract Skill Bars:** Technical competencies are strictly categorized by domain (Backend, Frontend, Cloud/DevOps, Databases, Architecture) with demonstrable scope.
4. **Pure Vanilla Modern Stack:** Built with HTML5 semantic markup, modern CSS3 (custom properties, CSS Grid, Flexbox, glassmorphism, responsive tokens), and Vanilla JavaScript ES6+ (no external bloat).
5. **Aesthetic Excellence (UI/UX Pro Max):**
   - Palette: Dark Mode OLED primary (#0B0B10, #161620, #22C55E accent, #3B82F6 secondary), with seamless Light Mode toggle.
   - Typography: Outfit (display/headings), Inter (body readability), JetBrains Mono (code/metrics).
   - Icons: Crisp inline SVGs (no raw emojis as UI controls).
   - Accessibility: WCAG 2.1 AA compliant (contrast >= 4.5:1, keyboard focusable, `aria-*` tags, reduced-motion fallback).
