Backend & REST API Concluído & Documentado

FastAPI Pizzaria Delivery — Backend RESTful

API robusta para gerenciamento e delivery de pizzaria construída com Python, FastAPI, SQLAlchemy, PostgreSQL e autenticação JWT.

SITUAÇÃO

Necessidade de um backend seguro, assíncrono e tipado para controle dinâmico de cardápio, criação de pedidos e autenticação de clientes e administradores.

AÇÃO

Estruturação modular em rotas (auth_routes.py, order_routes.py), schemas de validação Pydantic, autenticação OAuth2 com JWT (Access/Refresh Tokens), senhas com bcrypt e injeção de dependências para sessões de banco de dados.

RESULTADO

API com 100% de documentação interativa automática no Swagger UI (/docs), rotas protegidas por token e cálculo dinâmico do valor total de pedidos.

Python 3 FastAPI SQLAlchemy Pydantic JWT / OAuth2 PostgreSQL Bcrypt

Sistema de Gestão Bancária Desktop

Aplicação desktop de operações bancárias em Python com interface moderna CustomTkinter, modelagem orientada a objetos (POO) e persistência JSON.

SITUAÇÃO

Desenvolver uma ferramenta desktop segura e intuitiva para cadastro de correntistas, controle de contas e realização de operações financeiras com extrato em tempo real.

AÇÃO

Concepção de classes de domínio (Cliente, Conta, Transacao, BancoService), criação de diagramas UML de classes, implementação de persistência em JSON e construção de UI moderna com CustomTkinter.

RESULTADO

Sistema com interface responsiva em modo escuro nativo, validação de saldos e limites de saque, feedback de erro visual e histórico de transações íntegro.
