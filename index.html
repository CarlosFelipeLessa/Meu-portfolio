Backend & Mensageria

PayStream — Motor de Liquidação e Idempotência Financeira

Situação

Gateways de pagamento apresentavam timeouts ocasionais durante picos de transações, gerando cobranças duplicadas e divergência de reconciliação contábil.

Ação

Implementei arquitetura orientada a eventos (EDA) com RabbitMQ para dead-lettering, Outbox Pattern com PostgreSQL e chave de idempotência distribuída via Redis com TTL dinâmico.

Resultado

Zero transações duplicadas em mais de 3.2M de eventos processados; recuperação automática em 100% dos timeouts e p99 mantido em 94ms.

CloudMetrics — Observabilidade e Telemetria em Tempo Real

Situação

A empresa gastava alto valor com ferramentas de APM proprietárias e os dashboards sofriam congelamento ao plotar séries temporais de 100+ instâncias de servidores.

Full Stack & E-commerce

DevStore — Checkout Transparente Serverless e Multi-Tenant

Situação

Monólito legado travava na Black Friday. Tempo de carregamento do checkout chegava a 4.8s, ocasionando abandono massivo de carrinho e perda de faturamento.

Ação

Desacoplei o módulo de checkout migrando para funções Serverless na AWS Lambda + DynamoDB com escalabilidade elástica, e refatorei o frontend com React e SSR com cache inteligente.

Resultado

Aumento de +31% na taxa de conversão; tempo de carregamento caiu para 0.8s (Lighthouse Score 99) e zero quedas durante o pico de tráfego.

React AWS Lambda DynamoDB API Gateway Stripe API Terraform
Cloud & Microsserviços

ScalerFlow — Motor de Processamento Assíncrono com K8s

Situação

Exportação de relatórios analíticos pesados e processamento de PDFs causavam esgotamento do pool de conexões HTTP da API principal.

Ação

Isolei as tarefas em workers distribuídos em Kubernetes com Horizontal Pod Autoscaler (HPA) baseado em profundidade de fila e rate limiting por cliente.

Resultado

100% de isolamento de carga da API transacional, tempo de processamento de lote 3x mais veloz e redução de 40% em custos ociosos de computação.

Go Kubernetes Redis Streams Prometheus Grafana Helm
